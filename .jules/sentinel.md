## 2024-08-26 - [Path Traversal & Unencoded URL]
**Vulnerability:** The `slug` parameter in `ModelScraper.detect_url` (used in `src/ollama_catalog/model_scraper.py`) was not properly URL-encoded and didn't check for path traversal sequences like `..`, which could lead to accessing unexpected URLs when constructing the Ollama URL.
**Learning:** Even though this application pulls from a public directory structure, it interacts with an API via strings constructed from potentially arbitrary or unchecked inputs. We must ensure special characters are URL-encoded, and because `urllib.parse.quote` does not encode `.`, we must explicitly validate against `..` to prevent path traversal issues. In Python, methods that raise validation exceptions (like `ValueError`) must be properly caught by the calling functions to ensure the app handles the error gracefully instead of crashing.
**Prevention:** Always validate and sanitize user-provided or externally-sourced strings used in URL paths. URL encode to handle special characters while keeping namespace slashes safe (e.g. `urllib.parse.quote(slug, safe="/")`), and add explicit validation blocks for unexpected or dangerous patterns like path traversal sequences (`..`).
