## 2024-05-18 - Prevent Git Argument Injection in subprocess calls
**Vulnerability:** Command argument injection vulnerability where user-supplied Git references (like branches, tags, or commit hashes) could begin with a hyphen (`-`) and be misinterpreted by Git as command line options (like `--` or `--help`), leading to unintended command execution behavior or errors.
**Learning:** Even when avoiding `shell=True` and using an array in `subprocess.run`, prepending user input to positional arguments that invoke commands like `git show` can cause those inputs to be parsed as options if they start with a hyphen. Using the `--` end-of-options delimiter is not sufficient for `git show` because it changes the semantics (Git treats arguments following `--` as pathspecs rather than revisions).
**Prevention:** Explicitly validate all user-supplied revision identifiers before passing them to Git, rejecting any string that starts with a hyphen (e.g., `if ref.startswith("-"): raise ValueError(...)`).
