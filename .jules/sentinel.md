## 2024-05-18 - Prevent Command Injection via Git Arguments
**Vulnerability:** The `git_show` function in `scripts/explore_catalog.py` and `scripts/render_catalog.py` blindly passes the user-provided `ref` argument into `subprocess.run(["git", "show", f"{ref}:{path}"])`. Although argument injection using `--` is not directly possible here because it's interpreted as a ref by git if placed before the path, an attacker can pass arbitrary git options if the `ref` starts with `-`, potentially causing unintended behaviors or even command execution depending on the git command and environment.
**Learning:** Even when using `subprocess.run` with a list of arguments (which avoids shell injection), passing untrusted input as the first part of an argument that git interprets as a revision or option can lead to argument injection vulnerabilities.
**Prevention:** Always validate that user-provided identifiers like git revisions do not start with `-` before passing them to git commands via `subprocess`.
